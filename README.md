Spider Climber is a fast-paced vertical arcade platformer where every landing, web swing, pickup, and near-miss counts. Bounce across a cyberpunk skyline, avoid aerial drones, collect web cells and rocket boosts, and build your score through precision, timing, and momentum.

How to Play
Land on platforms to earn points.

Chain successful landings to build your Flow multiplier.

Use Web Sling to pull toward higher platforms and recover from risky jumps.

Collect web cells to refill your available slings.

Grab rocket boosts for rapid vertical momentum.

Dodge drones closely to earn Near Miss bonus points.

Survive increasingly difficult platform patterns as your score rises.

Controls
Mobile
Hold the left or right side of the game area to steer.

Tap WEB SLING to swing toward a nearby platform.

Enable optional tilt steering in Options.

When tilt steering is enabled, tap anywhere on the game field to use Web Sling.

Desktop
Use A/D or Left/Right Arrow Keys to steer.

Press Space or Enter to use Web Sling.
